### Spring Boot
- Spring MVC needs a server to run.
- Spring Boot provides an embedded server (like Tomcat) that allows you to run your Spring MVC application without needing to deploy it to an external server.
- With Spring Boot, you can simply run your application as a Java application, and it will start the embedded server and host your Spring MVC application.
- Spring Boot is also called as Rapid Application Development (RAD) framework because it allows you to quickly set up and run Spring applications with minimal configuration.
- @SpringBootApplication annotation is a convenience annotation that combines @Configuration, @EnableAutoConfiguration, and @ComponentScan. It enables auto-configuration and component scanning in Spring Boot applications.
