### Dynamic Programming
- Each problem consist of a set of subproblems
- Optimal solution to the problem can be constructed from optimal solutions of its subproblems
- Dynamic programming is applicable when the problem has optimal substructure and overlapping subproblems
- DP has 2 main approaches:
    - Top-down with memoization
    - Bottom-up with tabulation
- Top-down with memoization:
    - Start with the original problem and break it down into smaller subproblems
    - Store the results of subproblems in a cache (memoization) to avoid redundant calculations
    - Recursive approach
- Bottom-up with tabulation:
    - Start with the smallest subproblems and iteratively build up to the original problem
    - Use a table (array) to store the results of subproblems
    - Iterative approach
