### RDMS ( Relational Database Management System )
- a way of storing data in table format
- columns/properties/attributes/fields: describe the data (e.g. name, age, city)
- rows/records: individual entries in the table (e.g. John, 30,
- cells: the intersection of a row and a column (e.g. John, 30, New York)

### DDL ( Data Definition Language )
- used to define and manage the structure of the database
- CREATE, ALTER, DROP, TRUNCATE, RENAME

### DML ( Data Manipulation Language )
- used to manipulate the data in the database
- transaction: a sequence of operations performed as a single logical unit of work
- INSERT, UPDATE, DELETE, MERGE

### DQL ( Data Query Language )
- used to query the database
- SELECT, WHERE, JOIN, GROUP BY, HAVING, ORDER BY, LIMIT, OFFSET

### DCL ( Data Control Language )
- used to control access to the database
- GRANT, REVOKE, DENY
