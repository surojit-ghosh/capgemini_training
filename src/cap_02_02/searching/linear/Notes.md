## Linear Search

Linear search is a straightforward algorithm used to find a specific value within a list. It works by checking each element in the list one by one until the desired value is found or the end of the list is reached.

### Time Complexity
- Best Case: O(1) - The target value is found at the first position.
- Average Case: O(n) - On average, half of the elements need to be checked.
- Worst Case: O(n) - The target value is not in the list, or it is at the last position.
